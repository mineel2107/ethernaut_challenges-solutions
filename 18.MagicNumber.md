The level demands us to use RAW EVM bytecode

There is no tricky solution without using BYTECODE.
It is completely theoritical.
I have deplyed the bytecode using js.
Below is the solution:

```javascript
const bytecode = "0x600a600c600039600a6000f3602a60005260206000f3";
const provider = new ethers.JsonRpcProvider(process.env.RPC_URL);
const wallet = new ethers.Wallet(process.env.PRIVATE_KEY, provider);

async function deploy() {
  const tx = {
    data: bytecode,
    gasLimit: 100000,
  };

  const transaction = await wallet.sendTransaction(tx);
  console.log("Transaction hash:", transaction.hash);

  const receipt = await transaction.wait();
  console.log("Contract deployed at:", receipt.contractAddress);
}
```
