Our Goal here is to Recover lost eth

We need to get the contract address to call any function on the contract.
We know that `contract Recovery` has created the `contract SimpleToken` whose eth we are trying to recover
We can check the transactions of `Recovery` contract to findout the address of `SimpleToken`

We know that `selfdestruct` sends all the eth to the address specified in the function call.
`destroy()` can be used to recover those eth from `SimpleToken`

We can Use the address as below to recover eth

```solidity
    contract RecoverFromSimpleToken{
        address lostContractAddress = 0x804076dd56c46414E7F3f7a16b52A6b12e814e76;
        address recoveryAddress = 0x6a0DAD43Ae9d3C9ABEbfF42a2217513b99DB1E3E;
        bytes4 constant funSign_destroy = bytes4(keccak256("destroy(address)")) ;

        function recoverFunds() public {
            (bool success,) = lostContractAddress.call(abi.encodeWithSignature("destroy(address)",recoveryAddress));
            require(success,"Transfer Failed");
        }
    }
```
